# ForgeTrack

ForgeTrack is a self-hosted project management platform inspired by Redmine, Linear, and GitHub Issues. It is built as a modular Rust monolith designed to evolve into a scalable, distributed system.

## Tech Stack

### Backend

- Rust
- Axum
- Tokio
- SQLx
- PostgreSQL

### Frontend

- Next.js
- TypeScript
- TanStack Query
- Zustand
- Tailwind CSS

### Infrastructure

- Docker Compose
